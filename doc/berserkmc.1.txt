BERSERKMC(1)
============
:doctype: manpage


NAME
----
berserkmc - a launcher and instance manager for Minecraft.


SYNOPSIS
--------
*berserkmc* ['OPTIONS']


DESCRIPTION
-----------
BerserkMC is an offline-only custom launcher for Minecraft that allows you to
easily manage multiple installations of Minecraft at once. It also allows you
to easily install and remove mods by simply dragging and dropping.
Here are the current features of BerserkMC.

OPTIONS
-------
*-d, --dir*='DIRECTORY'::
    Use 'DIRECTORY' as the BerserkMC root.

*-l, --launch*='INSTANCE_ID'::
    Launch the instance specified by 'INSTANCE_ID'.

*--alive*::
    Write a small 'live.check' file after BerserkMC starts.

*-h, --help*::
    Display help text and exit.

*-v, --version*::
    Display program version and exit.
*-a, --profile*='PROFILE'::
    Use the account specified by 'PROFILE' (only valid in combination with --launch).

EXIT STATUS
-----------
*0*::
    Success

*1*::
    Failure (syntax or usage error; configuration error; unexpected error).
